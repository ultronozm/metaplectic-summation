## Local Kubota projection

A word in scalars and shears acts on each row evaluation by a matrix and a root of unity. The multipliers at two rows of determinant one satisfy the Hilbert-symbol identity of §4, including when a coordinate vanishes. In a word with identity matrix these multipliers agree across every such pair. Every nonzero row is connected to $(1,0)$ by determinant-one pairs, so the word acts by one scalar. Compactly supported Jacquet lifts with a test weight localized in the first coordinate distinguish matrices with different first columns. Composition with one lower shear distinguishes their second columns. Thus the matrix is unique, composition defines a homomorphism, and the elementary matrices give surjectivity.
