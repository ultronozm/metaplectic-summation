# Exercises

The main thread of the paper as four short exercise sheets, in the style of Onishchik–Vinberg: each problem is quick, hints are at the end of each sheet, and there are no solutions.

1. The Fourier transform.
2. Symmetries, the basic vector and inversion.
3. Leading terms and a Poisson formula.
4. Voronoi formulas for Gauss sums.

Build in order with `latexmk -pdf FILE.tex`; later sheets refer to earlier ones through `xr`.
